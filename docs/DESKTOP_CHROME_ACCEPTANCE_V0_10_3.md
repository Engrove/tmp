# Desktop Chrome acceptance — v0.10.3

## Automatic capture

1. Load the browser package unpacked.
2. Link a ChatGPT conversation with automatic capture enabled.
3. Do not start a mission.
4. Produce a normal stable assistant answer.
5. Verify one automatic capture and Session Memory readback.
6. Produce an answer completed through terminal EIC protocol override.
7. Verify a delta capture occurs.
8. Close the side panel, produce another stable assistant answer, reopen the panel and verify background-owned capture readback.
9. Verify unchanged transcript identity creates no duplicate capture.

## Initial Nano review

1. Start a new extension application session.
2. Activate and canary-verify Nano.
3. Allow the first automatic capture.
4. Verify exactly one spontaneous settings/core-surface analysis begins.
5. Verify an information card shows summary, source IDs and proposed changes.
6. Verify no setting or core surface changes before acceptance.
7. Decline once and verify all content remains unchanged.
8. Use **Omvärdera med Nano** and obtain a new manual proposal.
9. Accept it and verify:
   - safe config readback;
   - content-addressed mandate versions when rewritten;
   - source-bound continuity reviewed context;
   - Nano session stale/restart handling when Nano mandate or quick profile changed.
10. Produce further captures and verify no second automatic review starts in the same appsession.

## Safety

- Transcript instructions do not change project ID, target mode, Mjölnar rollout, permissions or external effects.
- No credentials, cookies, tokens or attachment bodies are persisted in the proposal.
